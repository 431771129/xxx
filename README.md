# 🎈 智慧学习乐园 (Kids Learning App)

专为幼升小及小学低年级儿童设计的互动学习与习惯养成应用。采用 ** Cloudflare 云原生架构**（D1 数据库 + Workers API + Pages 前端），实现了“儿童端极简听说读练 + 家长端乘法门禁与阶段掌控”。

---

## ✨ 核心特色

- **📜 阶段化知识库**：涵盖拼音、英语词句与经典古诗，支持按年级（幼升小 / 一年级 / 二年级 / 三年级）一键切换内容。
- **🔊 原生 TTS 语音朗读**：无需加载额外音视频文件，利用浏览器内置 Web Speech API 实现标准朗读。
- **⭐ 习惯养成与打卡激励**：每日任务打卡获取星星奖励，可与现实生活中的激励机制联动。
- **🔒 家长验证门禁**：内置乘法口诀安全锁（如 `7 × 8 = ?`），防止孩子误入后台改动配置。
- **☁️ 云端多端同步**：数据存储于 Cloudflare D1 数据库，家庭多台设备随时同步进度与星星数。
